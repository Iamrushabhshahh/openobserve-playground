## How the project is run

- **Decisions:** the lead maintainer decides, after discussion in the issue or pull request.
  Bigger design changes are written down first (an issue, or an ADR where the repo has them).
- **Reviews:** every pull request needs one maintainer approval and a green CI run.
- **Releases:** versions follow [SemVer](https://semver.org) and are listed in
  [CHANGELOG.md](CHANGELOG.md).
- **Response time:** this is a personal project maintained in spare time. Expect a first reply
  to issues and pull requests within 7 days.

## Becoming a maintainer

Contributors who have landed several good pull requests and helped others in issues may be
invited to join as maintainers. Open an issue if you want to help maintain openobserve-playground.
