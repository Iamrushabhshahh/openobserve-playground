# Security

## Reporting a vulnerability

Please **do not** open a public issue. Use GitHub's
[private vulnerability reporting](https://github.com/Iamrushabhshahh/openobserve-playground/security/advisories/new).
You will get a reply within 7 days, and a fix or a plan within 30 days for confirmed issues.

## Supported versions

Only the latest commit on `main` is supported.

## What this repo does with secrets

| Secret | Where | Rule |
|---|---|---|
| OpenObserve root login | `.env` (mode 600, generated by `make up`) | Never committed; `.gitignore` covers every `.env` variant |
| OpenObserve credentials for Claude Code | `~/.claude/settings.json` (Basic auth header) | Written by `make claude-code`, removed by `make claude-code-off`; both back the file up first |
| agent-obs MCP credentials | Claude Code's MCP config (`make mcp-install`) | Read-only tools by default; writes need `AGENT_OBS_ALLOW_WRITES=1` |

## Safe defaults, and where to change them

- **Prompt and tool content are not recorded** by default. `CONTENT=1 make claude-code` turns
  them on for your own debugging; don't do that on a shared OpenObserve.
- **`ZO_SKIP_SSRF_CHECKS=true`** in `docker-compose.yml` lets alerts reach services on your
  laptop. It is for local use only. Remove it on any server other people can reach.
- The playground binds to `localhost:5080` with a single root user. It is a laptop setup, not a
  production deployment.
