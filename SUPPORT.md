# Getting help

1. Read the [README](README.md) and the troubleshooting docs linked from it.
2. Search [existing issues](https://github.com/Iamrushabhshahh/openobserve-playground/issues?q=is%3Aissue).
3. Still stuck? [Open an issue](https://github.com/Iamrushabhshahh/openobserve-playground/issues/new/choose) with what you
   ran, what you expected, and what happened (logs help, secrets removed).

This repo covers the playground setup, dashboards, demo data and the agent-obs MCP server. Out of scope: bugs in OpenObserve or Claude Code themselves (report those upstream), and OpenObserve Cloud or Enterprise licensing questions.

Security problems: do **not** open a public issue. See [SECURITY.md](SECURITY.md).
